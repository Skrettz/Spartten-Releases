# 🚀 Spartten Releases

Repositório oficial de distribuição e atualizações automáticas do **Spartten Downloader**.

---

### 📦 Sobre este Repositório
Este é o diretório central onde ficam hospedadas todas as versões públicas compiladas, instaladores oficiais e atualizações contínuas do **Spartten Downloader**. 

O aplicativo utiliza este repositório para verificar periodicamente se há novas versões disponíveis e aplicar atualizações de forma automática e segura através do manifesto `latest.json`.

---

Todos os pacotes de instalação e atualizações acompanham assinaturas criptográficas (`.sig`) validadas pelo Minisign para garantir total autenticidade e segurança dos arquivos.
